Mọi thứ bạn cần trong một lệnh

TVDL gói sẵn yt-dlp và ffmpeg thành một menu tiếng Việt dễ dùng, kèm các tiện ích mà dòng lệnh thuần còn thiếu.

🎬

Đa nền tảng

Tải video từ YouTube, Facebook, Instagram, X và Xiaohongshu. Tự nhận diện nền tảng từ URL.

🎚️

Chọn chất lượng 1–8

Từ tốt nhất đến 360p, hoặc chỉ audio. Chất lượng mặc định được ghi nhớ cho lần tải sau.

🎧

Audio MP3 / M4A / OPUS

Tách audio bằng ffmpeg, không giả bitrate. Hỗ trợ cả playlist ở chế độ chỉ tải audio.

📃

Tải playlist

Tải toàn bộ, một khoảng (1–10) hoặc danh sách tuỳ chọn như 1,3,5; đặt tên file theo thứ tự.

🍪

Cookie thông minh

Dán cookie Netscape, JSON hay chuỗi Cookie: đều được. Tự chuyển định dạng, sao lưu bản cũ và xác nhận rõ ràng.

🀄

Xiaohongshu thông minh

Tự tách link chia sẻ /login?redirectPath=… và đọc trực tiếp trang để lấy luồng video, kể cả khi yt-dlp chưa hỗ trợ.

Lệnh tvdl & tự cập nhật

Cài một lần để gõ tvdl từ bất kỳ đâu. Cập nhật từ GitHub bằng tvdl --update, có kiểm tra và sao lưu.

🛠️

Ổn định & dễ sửa lỗi

Lịch sử tải, log lỗi chi tiết, kiểm tra hệ thống, gợi ý xử lý theo từng loại lỗi. Không cần root.

Cài đặt

Chạy trong vài phút

Cần Termux (nên cài từ F-Droid). Sao chép từng khối lệnh bên dưới.

# 1. Cập nhật gói và cài phụ thuộc
pkg update
pkg install python ffmpeg curl
python -m pip install -U yt-dlp

# 2. Tải TVDL và cài lệnh tvdl
curl -fsSL https://raw.githubusercontent.com/khahdihdz/tvdl/main/tvdl.sh -o tvdl.sh
bash tvdl.sh --install

# 3. Mở TVDL
tvdl
Cấp quyền bộ nhớ: chạy termux-setup-storage một lần để TVDL lưu file vào thư mục Download. Nếu muốn tự cập nhật sau này, chỉ cần gõ tvdl --update.

Cài phụ thuộc

Python, ffmpeg, curl và yt-dlp — tất cả đều có sẵn trong kho Termux/pip.

Cài lệnh tvdl

Script tự chọn $PREFIX/bin trên Termux hoặc ~/.local/bin trên Linux.

Chọn nền tảng & tải

Dán URL, xem thông tin, chọn chất lượng rồi xác nhận. File nằm trong thư mục bạn đã chọn.

Gỡ cài đặt an toàn

Chạy tvdl --uninstall. TVDL chỉ xóa file do chính nó cài (nhận diện bằng marker), không đụng tới lệnh trùng tên của công cụ khác.

Tham khảo

Các lệnh thường dùng

Không có tham số, TVDL mở menu tương tác. Các tham số dưới đây dùng cho script hoặc thao tác nhanh.

LệnhÝ nghĩa
tvdlMở menu chính
tvdl --installCài lệnh gõ nhanh tvdl
tvdl --uninstallGỡ lệnh tvdl đã cài
tvdl --statusXem trạng thái và vị trí cài lệnh
tvdl --updateCập nhật TVDL từ GitHub
tvdl --no-colorTắt màu ANSI
tvdl -yKhông hỏi xác nhận (dùng với --install, --uninstall, --update)
tvdl --helpHiển thị trợ giúp
tvdl --versionHiển thị phiên bản
 
# Cập nhật TVDL lên bản mới nhất
